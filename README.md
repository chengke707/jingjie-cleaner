# 净界 · Jingjie Cleaner

一个 Windows 本地空间清理与系统修复小工具。把准备处理的内容解释清楚，由你选择，再执行并留下记录。

**当前版本：0.3.2，实验版本。** 仅提供源码运行方式，尚无独立安装包。适用于 Windows 10/11，需要安装 [Node.js 18 或更高版本](https://nodejs.org/)（建议使用仍受支持的 LTS 版本）。

## 三步开始

1. 点击仓库上方 **Code → Download ZIP**，解压到固定位置。
2. 安装 Node.js 后，双击文件夹中的 `start.cmd`。
3. 在打开的窗口中选择“深度扫描”或“修复中心”。

更简单的操作说明见 [用户指南](用户指南.md)。不需要运行 `npm install`；本项目没有 npm 第三方运行依赖。关闭窗口后服务仍运行，双击 `stop.cmd` 可停止。

## 能做什么

- 读取系统盘容量，扫描过期临时文件、崩溃转储、DirectX 缓存和 Windows 错误报告。
- 先将所选文件移入隔离区，支持恢复；独立确认永久删除后才释放空间，并记录文件路径、数量和大小。
- 结合安装清单及运行进程，列出长期未修改的**疑似**卸载残留，默认不勾选。
- 检查 Windows 更新、组件库、DNS/代理配置和系统盘空间。
- 组件库快速检查遇到权限不足时，单独请求 Windows 授权，即使复用了普通权限的后台也能检查；显示实际错误和原始输出。快速检查只查询已有损坏记录，不执行修复。
- 以大白话说明修复用途；勾选后点击一次“开始修复”，顺序执行 DNS 缓存刷新或 Windows DISM/SFC 修复，显示结果及原始输出。
- 系统修复后分别用 DISM ScanHealth 和 SFC verifyonly 复检，两项通过才确认通过；识别空间不足、缺少官方修复文件、等待重启等原因，提供下一步入口。可切换历史记录，旧记录不冒充已复检。

## 使用前了解

- 同盘隔离不会立即腾出空间；永久删除无法通过本应用撤销。恢复遇到同名文件不会覆盖。
- 疑似残留可能包含仍需要的设置或数据，务必先看目录内容。扫描有数量、深度和时间限制，并非全盘审计。
- 修复可能需要一次 Windows 管理员授权。应用不会自动重启，不会下载第三方补丁；打开更新或存储设置不等于修复完成。
- 系统盘不足 5 GB 时整批修复不会启动，建议预留 10 GB；这是避免低空间失败的起点，不能保证 5 GB 对每台电脑都足够。仍需查看实际执行及复检结果。
- 网络配置检查不能证明网络连通，DNS 刷新不能解决所有断网问题；DISM/SFC 不能保证修好第三方应用。
- 主界面通过本机 `127.0.0.1:4173` 提供；扫描结果、隔离数据与修复日志保存在本地。Windows 官方修复命令可能联网。
- 请保留应用文件夹中的 `.quarantine` 和 `.repairs`；`.checks` 保存管理员快速检查结果。不要把这些本地数据上传到仓库。不要从隔离区删除应用目录。
- 图形窗口优先使用 Edge，无 Edge 时通过默认浏览器打开。`launch.ps1` 也兼容开发环境已有的 Node.js 路径。

## 开发与验证

Windows 上在仓库目录运行：

```powershell
node --check server.mjs
node tests/run.mjs
```

测试使用合成文件和替代修复命令，验证隔离/恢复/删除边界、残留识别、修复选择、进度持久化及失败处理。不会实际执行系统修复。另可运行 `node tests/verify-interface.mjs` 做 Edge 浏览器交互验证（需要 Edge，使用本机端口 4176/9226）。测试产物保存在忽略的 `work/` 目录或 Windows 临时目录，不随源码提交。
