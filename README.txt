净界 - Windows 空间管家 0.3（本地应用）

最简单的操作说明见 用户指南.md，项目介绍与许可见 README.md。
内嵌图标的第三方许可证全文见 THIRD_PARTY_NOTICES.md。

启动方式
1. 双击 start.cmd。
2. 使用 Edge 的独立窗口打开；无 Edge 时使用默认浏览器。
3. 关闭窗口不会结束本地服务。双击 stop.cmd 停止服务。
4. 服务仅监听 http://127.0.0.1:4173，不上传文件和扫描结果。

当前可用能力
- 读取 C 盘真实总容量和可用空间。
- 扫描超过安全期限的临时文件、崩溃转储、DirectX 缓存和 Windows 错误报告。
- 读取 Windows 注册表中的已安装应用。
- 清理项先移动到本应用目录内的 .quarantine 隔离区。
- 支持将隔离文件恢复到原始位置。
- 隔离区逐项永久删除，二次确认后释放空间；永久删除不可在净界撤销。
- 同盘隔离不会立即释放空间，不会定时自动删除。
- 隔离、恢复和永久删除会写入持久清理记录，可查看文件原始路径、数量和大小；仅扫描不记作清理。
- 卸载残留扫描会核对注册表安装清单、Microsoft Store 应用及运行进程，只列出超过 30 天未修改且无法匹配的用户级目录。
- 修复中心可检查 Windows 更新、待重启、组件存储、DNS/代理和系统盘空间。
- 修复操作只使用 Windows 更新设置、存储设置、ipconfig、DISM 和 SFC。
- 修复中心逐项说明用途和影响，勾选后点击一次“开始修复”，应用不再重复确认。可不做快速检查而直接执行所选修复。
- DNS 刷新和系统文件修复在同一批次顺序执行，Windows 可能要求一次管理员授权；无法跳过系统授权。
- 每步显示等待、执行中、已完成、未成功或需要查看结果；取消授权不会记为修复成功。不会自动重启。
- 最近一次修复进度与 Windows 输出保存在 .repairs，刷新或重新打开应用仍可查看；历史批次日志保留在各批次目录。
- 系统文件检查完成后仍需查看 Windows 原始输出确认结果，不能仅凭命令退出就保证所有故障解决。
- 更新与存储设置属于手动辅助，不加入自动修复批次，也不记作已修复。

安全边界
- 不扫描桌面、文档、下载、图片等个人目录。
- 不会自动清理；先由用户选择隔离，再独立确认永久删除。
- 只允许处理内置白名单目录，拒绝符号链接和目录越界。
- 不会安装第三方补丁；Windows 补丁仍由系统自带的 Windows 更新完成。
- 残留识别是保守推断，便携软件和已停用但仍需保留的数据可能被列出，必须人工审查。
- 安装清单中的容量由注册表估算，日期是安装日期，无法得知最近使用时间。
- 若扫描后文件发生变化，或文件被占用，则跳过；需要重新扫描核对。
- 恢复遇到同名文件不会覆盖，未恢复文件继续保留。
- 应用目录与待清理目录必须在同一磁盘，否则文件隔离会跳过。
- 扫描每类目录最多访问约 8 万个条目、12 层；结果不是全盘残留审计。
- 不扫描个人目录指不扫描桌面/文档/下载等已知目录；自行放在临时目录的文件仍需审查。

验证
- 已验证系统信息、中文安装清单及真实只读扫描。
- 14 项合成文件检查通过，包含隔离/恢复/重启持久化/恢复冲突/永久删除确认。
- 不使用真实用户文件测试清理操作。

运行要求
- Windows 10/11
- Node.js 18 或更高版本
